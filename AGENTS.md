# Trabajo en LIFT Design

Este repositorio mantiene la skill de contenido LIFT. La identidad visual ya existe en otro directorio del proyecto; localizarla según `skills/lift-content-production/references/identidad-existente.md`.

- Para crear o editar un carrusel, historia, contenido LAB o BUILDERS, leer y aplicar `skills/lift-content-production/SKILL.md` y sus referencias pertinentes.
- Para mejorar la skill, editar la fuente de este repositorio; no duplicar recursos de identidad ni cambiar posteos históricos sin encargo.
- Antes de entregar una actualización, ejecutar `python3 scripts/validate.py`. Mantener VERSION, la versión de SKILL.md y CHANGELOG.md coherentes.
- No registrar validación editorial de Nahuel que no haya ocurrido. No convertir una actualización de instrucciones en autorización para publicar.
- Las aprobaciones, accesos, datos de atletas y configuración local no se guardan en el repo.
